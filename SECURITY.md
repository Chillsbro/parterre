# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions,
or pull requests.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/Chillsbro/parterre/security/advisories/new

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Remove unrelated credentials and personal data from supporting
material.

You should receive an acknowledgment within seven days. Please allow time for
the issue to be investigated and fixed before disclosing it publicly.

## Supported versions

Security fixes are provided for the latest released version of Parterre.
